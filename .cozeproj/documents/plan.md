# 久久金运营部数据看板 - 实施计划

## 概述

搭建久久金运营部整体数据看板，基于运营部8大业务模块（美团、高德、图文线、短视频、小红书、GEO、私域、储备渠道）及跨部门协同数据，实现"管理层汇报展示 + 日常运营监控"双重场景。平台：Web。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js 16 (App Router) | 复杂全栈应用，支持后端API Routes处理数据聚合 |
| UI组件 | shadcn/ui | 企业级组件库，适合数据看板场景 |
| 图表库 | Recharts | React原生图表库，与shadcn/ui风格统一 |
| 样式 | Tailwind CSS 4 | 快速开发，响应式支持好 |
| 数据模拟 | Mock数据 + API Routes | 初期使用汇报中的真实数据，后续可对接实际数据源 |

## 功能模块

### 1. 总览仪表盘（首页）
- **核心KPI卡片**：GTV总额、门店覆盖率、客服响应时长、私域用户数、内容曝光量
- **模块健康度雷达图**：8大模块完成度可视化
- **关键趋势图**：近3个月GTV、客资转化、内容曝光趋势
- **预警指标**：未达标项高亮提示（如客服响应7.6分钟 vs 目标30秒）

### 2. 美团模块详情页
- **核心指标**：GTV交易额（2,431.67万/季度）、门店上线率（60.8%）、推广覆盖率（9.3%）
- **数据表格**：269家门店GTV排名、32家零GTV门店清单、115条同城互抢记录
- **转化漏斗**：搜索曝光 → 客资 → 加V → 成交
- **客服数据**：响应时长458.7秒、30秒回复率49.6%、客资积压率45.4%

### 3. 内容矩阵详情页（图文线+短视频+小红书）
- **图文线**：5平台阅读量趋势（公众号4,940↑96%、知乎2,060↓45%、百家号867↓40%）
- **短视频**：12个有效号播放量、门店矩阵进度（20家试点→70家→269家）
- **小红书**：21个有效账号数据、获客成本（目标133元/条 vs 当前400元/条）
- **产能统计**：人均产出、AI赋能前后对比

### 4. 私域运营详情页
- **用户规模**：企微56,251人、支付宝粉丝群28,990人、会员2,701人
- **转化数据**：回收转购买转化率0.2%、加V率趋势
- **标签体系**：14项三级标签完成度
- **激活进度**：5,000种子用户首批激活状态

### 5. 跨部门协同看板
- **客服部数据**：周客资5,250+、加V率（点击未下单2.4%、下单成功37%、400电话33%）
- **门店管理部**：297家门店执行率、渠道来源可信度（店员录入73.3%）
- **协同指标**：客服-私域交接效率、门店素材提交率

### 6. 行动计划追踪页
- **里程碑时间线**：7月止血+基建 → 8-9月扩面 → Q4全覆盖
- **任务完成度**：P0/P1/P2任务进度条
- **责任人视图**：按执行人（周俊良、宋思滢、高链谦等）展示任务分布

## 实施步骤

### 阶段一：原型设计
加载 `design-canvas` 技能，按该技能中的流程完成原型设计。原型设计完成后提示用户如果不需要修改则进入开发阶段，你调用done工具提交等候用户确认。用户确认后进入下阶段开发。

### 阶段二：代码开发
1. **初始化项目与基础架构**：使用 `coze init` 初始化 Next.js 项目，配置 shadcn/ui 组件库，搭建全局 Layout（侧边导航+顶部栏）、路由结构、Mock数据层。关键文件：`src/app/layout.tsx`、`src/lib/mock-data.ts`、`src/components/layout/`
2. **总览仪表盘开发**：实现首页KPI卡片组、模块健康度雷达图、关键趋势折线图、预警指标高亮。关键文件：`src/app/page.tsx`、`src/components/dashboard/`
3. **美团模块详情页开发**：实现GTV数据卡片、门店排名表格、转化漏斗图、客服数据面板。关键文件：`src/app/meituan/page.tsx`、`src/components/meituan/`
4. **内容矩阵详情页开发**：实现图文线多平台阅读量对比、短视频账号数据、小红书获客成本分析、产能统计图表。关键文件：`src/app/content/page.tsx`、`src/components/content/`
5. **私域运营与跨部门协同页开发**：实现私域用户规模与转化数据、客服部周客资与加V率、门店执行率看板。关键文件：`src/app/private-domain/page.tsx`、`src/app/collaboration/page.tsx`
6. **行动计划追踪页与全局优化**：实现里程碑时间线、任务进度条、责任人视图；响应式适配、数据加载状态、空态处理。关键文件：`src/app/actions/page.tsx`、`src/components/actions/`
7. **执行代码检查与验证**：运行 TypeScript 类型检查、ESLint 代码检查、构建验证，确保无错误后交付。
